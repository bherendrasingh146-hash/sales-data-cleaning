# Sales Data Cleaning and Analysis Project

This repository contains a complete Python Pandas workflow for cleaning, analyzing, and summarizing raw sales datasets.

## Project Structure
- `day2_cleaning.ipynb` (or `.py`): The primary Python script containing the data cleaning logic.
- `cleaned_data.csv`: The final processed dataset generated automatically by the code.

## Steps Completed
1. Data Definition & Exploration
2. Missing Value Imputation (`fillna`)
3. Handling Invalid/Negative Values (`.abs()`)
4. Removing Duplicates (`drop_duplicates`)
